# AI matching concept visuals

Standalone product mockups for discussion and presentation use. These images are not connected to a working feature in the web app.

## Files

- `flatmate-preference-match.png` — compares two students' living preferences, location and budget compatibility.
- `same-supplier-location-match.png` — matches students who selected the same residence from the same supplier.
- `semester-handover-schedule-match.png` — illustrates an outgoing winter-semester tenant and an incoming semester-two tenant with a turnover window.

## Generation notes

Generated with the built-in image generation tool as high-fidelity mobile UI concepts. The shared direction used EduStay HK's navy, teal, mint and warm-paper palette; friendly illustrated student profiles; clear match reasoning; fictional personal details; and no implication of a confirmed booking.

Provider names in these concepts are informational placeholders. Confirm permission and current commercial details before using any supplier name in public marketing.
